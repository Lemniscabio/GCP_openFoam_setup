Methodology Notes

All tests use 16 vCPU and the same OpenFOAM workload. C2 does not offer the tested high-CPU shape, so c2-standard-16 is the available C2 comparison.

Benchmark provenance: every test run used the single-phase OpenFOAM case case_0186, uploaded under gs://of-cases/cases/case_0186/.

Total cost is calculated from the supplied hourly rate multiplied by runtime: C2D 3.40 × $0.60 = $2.04, C4D 3.98 × $0.64 = $2.55, C2 4.10 × $0.67 = $2.75, and C3D 7.83 × $0.60 = $4.70.

Solver logs independently confirmed the unusual C3D result: C2D solver clock time was 10,988s, while C3D was 26,987s for the same final simulation time.
